## Menjalankan ulang

```bash
npm ci
npm run lint
npm run typecheck
npm run test
npm run build
npm audit --omit=dev
```

Jalankan build produksi di terminal terpisah:

```bash
npm run start -- --port 3107
```

Lalu jalankan UAT:

```bash
npm run test:uat
```

Runner memakai Chrome macOS secara default. Atur `CHROME_PATH` untuk lokasi browser lain dan `UAT_BASE_URL` jika alamat pengujian berubah. Screenshot ditulis ke direktori temporer `smart-warehouse-uat`. Semua permintaan Supabase pada runner ini disimulasikan; kelulusan runner tidak membuktikan instalasi migrasi atau realtime pada database aktif.

Uji SQL hanya pada database pengembangan dengan Auth Supabase:

```bash
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f supabase/schema.sql
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f supabase/tests/inventory.sql
```
